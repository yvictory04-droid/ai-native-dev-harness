# Implementation Planner

## Description

Translate product and UI requirements into executable engineering steps.

## When to Use

Use this skill during the Agentic Product Engineering Harness workflow when its stage is reached.


## Procedure

1. Read context, PRD, review, and UI/FRD.
2. Propose data model changes.
3. Propose backend/API changes.
4. Propose frontend changes.
5. Define migration, compatibility, and rollback.
6. Break work into small sequential steps.

## Output

Create `05_IMPLEMENTATION_PLAN.md` with:

- implementation summary
- files likely to change
- database changes
- API changes
- backend logic
- frontend logic
- permission logic
- error handling
- migration plan
- rollback plan
- step-by-step task list

## Anti-Patterns

- Do not write code in this phase.
- Do not create a plan that requires massive unreviewable edits.
