# PRD Reviewer

## Description

Review the PRD with skepticism and identify gaps before implementation begins.

## When to Use

Use this skill during the Agentic Product Engineering Harness workflow when its stage is reached.


## Procedure

1. Read the PRD as if you are responsible for preventing rework.
2. Challenge ambiguous scope.
3. Identify hidden risks, missing edge cases, and weak acceptance criteria.
4. Recommend revisions.

## Output

Create `03_PRD_REVIEW.md` with:

- major concerns
- missing requirements
- unclear boundaries
- edge cases
- dependency risks
- acceptance gaps
- required revisions
- approval status

## Anti-Patterns

- Do not simply praise the PRD.
- Do not approve vague requirements.
