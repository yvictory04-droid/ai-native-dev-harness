# UI / FRD Writer

## Description

Convert approved PRD into page-level functional and interaction requirements.

## When to Use

Use this skill during the Agentic Product Engineering Harness workflow when its stage is reached.


## Procedure

1. Identify user roles and page entry points.
2. Define pages, components, tables, filters, forms, modals, and actions.
3. Define empty, loading, error, success, and permission states.
4. Define UX behavior for edge cases.

## Output

Create `04_UI_FRD.md` with:

- page map
- role access
- page purpose
- main interactions
- component requirements
- table fields
- form fields
- state behavior
- edge cases
- acceptance checklist

## Anti-Patterns

- Do not only describe visual style.
- Do not skip error and empty states.
