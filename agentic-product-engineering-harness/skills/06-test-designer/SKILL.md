# Test Designer

## Description

Design verification before code is written.

## When to Use

Use this skill during the Agentic Product Engineering Harness workflow when its stage is reached.


## Procedure

1. Read PRD and implementation plan.
2. Convert acceptance criteria into executable tests.
3. Cover happy path, failure path, edge cases, permissions, and regression.
4. Define commands to run.

## Output

Create `06_TEST_PLAN.md` with:

- test strategy
- unit tests
- integration tests
- E2E tests
- permission tests
- regression tests
- manual smoke tests
- commands
- pass/fail criteria

## Anti-Patterns

- Do not say "add tests" generically.
- Do not skip negative cases.
