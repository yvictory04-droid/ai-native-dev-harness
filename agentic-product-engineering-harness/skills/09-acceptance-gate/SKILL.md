# Acceptance Gate

## Description

Determine whether a feature is ready to merge or release.

## When to Use

Use this skill during the Agentic Product Engineering Harness workflow when its stage is reached.


## Procedure

1. Review all artifacts.
2. Verify PRD acceptance criteria.
3. Verify implementation plan completion.
4. Verify test plan execution.
5. Verify known risks and unresolved items.
6. Produce final acceptance decision.

## Output

Create `09_ACCEPTANCE_REPORT.md` with:

- feature summary
- artifact checklist
- test results
- acceptance criteria status
- unresolved issues
- release risk
- final decision: approved / blocked

## Anti-Patterns

- Do not approve with unresolved critical issues.
- Do not confuse demo success with production readiness.
