# Gemini Context File

This project uses the Agentic Product Engineering Harness.

## Instruction

Before implementing non-trivial work, produce or update the following artifacts:

1. Context analysis
2. PRD
3. PRD review
4. UI / FRD
5. Implementation plan
6. Test plan
7. Review report
8. Acceptance report

## Operating Style

- Be structured.
- Be skeptical.
- Prefer explicit scope over vague ambition.
- Prefer testable requirements over loose descriptions.
- Prefer small implementation steps over large rewrites.

本项目要求 Gemini 在执行复杂任务前，先完成上下文、PRD、审查、UI/FRD、实现方案和测试计划。  
不要直接进入大规模代码修改。
