# 01_CONTEXT — AI Phone Example

## Product Summary

AI Phone is an operational voice product that handles inbound calls, identifies intent, collects or verifies necessary information, completes structured workflows, and escalates to a human when needed.

## User Roles

- Operator
- Supervisor
- Admin
- End caller

## Core Modules

- Live Calls
- Call Detail
- Exception Queue
- Outbound Tasks
- Human Handoff
- Audit Trail

## Risks

- Wrong caller identification
- Low-confidence intent handling
- Failed external system update
- Missing human handoff path
- Incomplete audit trail

## Missing Information

- Exact identity verification rule
- Supported call intents
- External system APIs
- Escalation threshold
- Notification templates
