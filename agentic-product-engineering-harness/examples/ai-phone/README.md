# Example: AI Phone

This example shows how to use the harness for an AI phone product.

## Product Context

The system answers inbound calls, understands caller intent, verifies identity when needed, retrieves or updates structured records, sends confirmation messages, and escalates calls to a human when confidence is low or the scenario is out of scope.

## First Version Scope

- live call handling
- call status monitoring
- call detail review
- exception queue
- outbound call tasks
- human handoff
- audit trail
