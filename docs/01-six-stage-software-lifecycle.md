# 01. Six-stage Software Lifecycle

## 1. 需求分析

目标：搞清楚要做什么、给谁用、做到什么算完成。  
产出：PRD、用户故事、功能清单、页面清单、验收标准。

## 2. 系统设计

目标：决定系统怎么搭、代码怎么分、数据怎么流、模块怎么协作。  
产出：ARCHITECTURE、模块划分、技术方案、接口设计、权限模型。

## 3. 编码实现

目标：按照需求和设计，把功能做出来。  
产出：源代码、Commit、功能分支、PR。

## 4. 测试验证

目标：证明系统能不能用、有没有错、会不会崩。  
产出：测试报告、Bug 列表、构建结果、测试通过记录。

## 5. 部署发布

目标：把通过测试的代码上线，让用户能用。  
产出：Release Note、部署记录、发布清单、回滚方案。

## 6. 运维维护

目标：系统上线后持续保证稳定运行，并不断迭代。  
产出：Bug 修复记录、Incident Report、Debug Playbook、Rollback 记录。
